# Apple Device Suport - Windows Only
As it is against Apple's EULA to distribute the necessary components for building this project, they need to be downloaded separately.

Three files are required:
1. Bonjour64.msi
2. BonjourSDK64.msi
3. AppleMobileDeviceSupport64.msi

## Bonjour
1. Download the BonjourSDK from [softpedia](https://www.softpedia.com/get/Programming/SDK-DDK/Bonjour-SDK.shtml#download).
2. Open `bonjoursdksetup.exe` in 7zip.
3. Extract both Bonjour64.msi and BonjourSDK64.msi to this folder.

## AppleMobileDeviceSupport
1. Download [iTunes](https://www.apple.com/itunes/download/win64).
2. Open `iTunes64Setup.exe` in 7zip.
3. Extract AppleMobileDeviceSupport64.msi to this folder.
